# ОписаниеОкружения

Деплой-окружение джобы (`environment`). Доступ: `Задача.Окружение`

## Поля

| Поле | Тип | YAML-ключ |
|------|-----|-----------|
| `Имя` | Строка | `name` |
| `УРЛ` | Строка | `url` |
| `ПриОстановке` | Строка | `on_stop` (имя стоп-джобы) |
| `Действие` | Строка | `action` (см. модуль `ДействияОкружения`) |
| `АвтоОстановка` | Строка | `auto_stop_in`, например `1 week` |

## Валидации при генерации

- Недопустимое действие → исключение с перечнем допустимых (см. `ДействияОкружения.Допустимые()`)
- Заполнено что-то, но `Имя` пустое → исключение (url без name невалиден)
- `ПриОстановке` ссылается на несуществующую джобу → исключение

Пустое окружение → ключ не выводится.

## Пример (review-app паттерн)

```bsl
// Джоба развёртывания
Деплой.Окружение.Имя = "review/$CI_COMMIT_REF_SLUG";
Деплой.Окружение.УРЛ = "https://$CI_ENVIRONMENT_SLUG.example.com";
Деплой.Окружение.ПриОстановке = "stop-review";
Деплой.Окружение.АвтоОстановка = "1 week";

// Стоп-джоба
Стоп.Окружение.Имя = "review/$CI_COMMIT_REF_SLUG";
Стоп.Окружение.Действие = ДействияОкружения.Остановка();
```
