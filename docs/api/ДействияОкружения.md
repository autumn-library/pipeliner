# ДействияОкружения

Модуль-константа действий для `environment:action`. Источник правды — именованные методы, набор `Допустимые()` наполняется из них.

## Методы

| Метод | Значение | Смысл |
|-------|----------|-------|
| `Запуск()` | start | Развёртывание (дефолт) |
| `Подготовка()` | prepare | Подготовить окружение без создания |
| `Остановка()` | stop | Остановить окружение |
| `Проверка()` | verify | Проверить окружение |
| `Доступ()` | access | Только доступ |

## Допустимые()

Массив всех значений — используется для валидации в генераторе.

## Пример

```bsl
СтопДжоба.Окружение.Действие = ДействияОкружения.Остановка();
```
