# ОписаниеПовтора

Политика повторных запусков джобы (`retry`). Доступ: `Задача.Повтор`

## Поля

| Поле | Тип | YAML-ключ |
|------|-----|-----------|
| `Повторы` | Число | `max` (или скалярный `retry`) |
| `ПовторыКогда` | Массив из Строка | `when` |
| `КодыВыхода` | Массив из Числа | `exit_codes` |

## Методы

### ДобавитьУсловие(Условие)

Добавляет условие повтора с **валидацией**. Условия берите из модуля `УсловияПовтора`:

```bsl
Задача.Повтор.ДобавитьУсловие(УсловияПовтора.СбойСкрипта());
Задача.Повтор.ДобавитьУсловие(УсловияПовтора.СбойРаннера());
```

### ДобавитьКодВыхода(Код)

Код выхода, при котором повторять:

```bsl
Задача.Повтор.ДобавитьКодВыхода(42);
```

## Вывод

| Задано | YAML |
|--------|------|
| Только число | `retry: 2` |
| Одно условие | `retry: {max: 2, when: script_failure}` |
| Несколько условий | `when: [...]` (массив) |
| Дубли условий/кодов | Сворачиваются |

## Пример

```bsl
Задача.Повтор.Повторы = 2;
Задача.Повтор.ДобавитьУсловие(УсловияПовтора.СбойСкрипта());
Задача.Повтор.ДобавитьКодВыхода(42);
```
