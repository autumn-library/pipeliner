# ФабрикаЗадач

Реестр задач пайплайна. Создаёт описания задач и накапливает их для генератора.

Получение:

```bsl
Фабрика = Поделка.НайтиЖелудь("ФабрикаЗадач");
```

## Новая()

Создаёт новое описание задачи, регистрирует его в реестре и возвращает.

```bsl
Задача = Фабрика.Новая();
```

**Возвращаемое значение:** `ОписаниеЗадачи`

## Задачи()

Возвращает массив накопленных задач.

```bsl
Все = Фабрика.Задачи();
```

**Возвращаемое значение:** `Массив из ОписаниеЗадачи`

## Очистить()

Очищает реестр задач (используется в тестах для изоляции сценариев).
