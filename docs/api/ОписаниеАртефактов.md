# ОписаниеАртефактов

Артефакты джобы (`artifacts`). Доступ: `Задача.Артефакты`

## Поля

| Поле | Тип | YAML-ключ |
|------|-----|-----------|
| `Имя` | Строка | `name` |
| `Когда` | Строка | `when` |
| `ВремяХранения` | Строка | `expire_in` |
| `Пути` | Массив из Строка | `paths` |
| `Исключить` | Массив из Строка | `exclude` |
| `Неотслеживаемые` | Булево | `untracked` |
| `Публичный` | Булево | `public` |
| `ПоказыватьКак` | Строка | `expose_as` |
| `Отчеты` | Соответствие | `reports` |

## Методы

### ДобавитьПуть(Путь)

Добавляет путь в артефакты.

### ДобавитьИсключение(Путь)

Добавляет исключение (маску) из артефактов.

### ДобавитьОтчет(Тип, Путь)

Добавляет отчёт по типу с **валидацией** типа. Тип берите из модуля `ВидыОтчетов`:

```bsl
Задача.Артефакты.ДобавитьОтчет(ВидыОтчетов.Юнит(), "junit.xml");
Задача.Артефакты.ДобавитьОтчет(ВидыОтчетов.САСТ(), "gl-sast-report.json");
```

Недопустимый вид → исключение с перечнем допустимых.

### ДобавитьОтчетПокрытия(Формат, Путь)

Отчёт покрытия `coverage_report` с валидацией формата (cobertura/jacoco/lcov/simplecov):

```bsl
Задача.Артефакты.ДобавитьОтчетПокрытия(ВидыОтчетов.Кобертура(), "coverage.xml");
```

## Пример

```bsl
Артефакты = Задача.Артефакты;
Артефакты.Имя = "$CI_JOB_NAME-artifacts";
Артефакты.ВремяХранения = "1 week";
Артефакты.ДобавитьПуть("dist/");
Артефакты.ДобавитьИсключение("dist/*.tmp");
Артефакты.ДобавитьОтчет(ВидыОтчетов.Юнит(), "junit.xml");
```
