# ОписаниеКэша

Кэш джобы (`cache`). Доступ: `Задача.Кэш`

## Поля

| Поле | Тип | YAML-ключ |
|------|-----|-----------|
| `Пути` | Массив из Строка | `paths` |
| `Ключ` | Строка | `key` |
| `КлючПоФайлам` | Массив из Строка | `key: files` |
| `КлючПоКоммитам` | Массив из Строка | `key: files_commits` |
| `ПрефиксКлюча` | Строка | `key: prefix` |
| `Когда` | Строка | `when` |
| `Политика` | Строка | `policy` |
| `Неотслеживаемые` | Булево | `untracked` |
| `БезЗащиты` | Булево | `unprotect` |
| `РезервныеКлючи` | Массив из Строка | `fallback_keys` |

## Методы

### ДобавитьПуть(Путь)

Добавляет путь в кэш.

### Всегда() / ПриУспехе() / ПриНеудаче()

Сахар для поля `Когда` (когда использовать кэш): `always` / `on_success` (по умолчанию) / `on_failure`.

### ТолькоЧтение() / ТолькоЗапись() / ЧтениеИЗапись()

Политика кэша: `pull` / `push` / `pull-push` (по умолчанию).

## Пример

```bsl
Задача.Кэш.ДобавитьПуть("vendor/");
Задача.Кэш.КлючПоФайлам.Добавить("packagedef");
```
