# ОписаниеКэша

Кэш джобы (`cache`). Доступ: `Задача.Кэш`

## Поля

| Поле | Тип | YAML-ключ |
|------|-----|-----------|
| `Пути` | Массив из Строка | `paths` |
| `ПрефиксКлюча` | Строка | префикс `key` |
| `КлючПоФайлам` | Массив из Строка | `key: files` |
| `Политика` | Строка | `policy` |
| `Неотслеживаемые` | Булево | `untracked` |

## Методы

### ДобавитьПуть(Путь)

Добавляет путь в кэш.

### ДобавитьКлючПоФайлам(Файл)

Добавляет файл в генерацию ключа.

## Пример

```bsl
Задача.Кэш.ДобавитьПуть("vendor/");
Задача.Кэш.ДобавитьКлючПоФайлам("packagedef");
```
