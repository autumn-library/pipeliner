# ОписаниеПараллельности

Параллельный запуск джобы (`parallel`). Доступ: `Задача.Параллельность`

## Поля

| Поле | Тип | YAML-ключ |
|------|-----|-----------|
| `Количество` | Число | `parallel` (число копий) |
| `Матрица` | Массив из Соответствие | `parallel.matrix` |

## Методы

### ДобавитьРядМатрицы(ИмяПеременной, Значения)

Независимый ряд матрицы с одной переменной:

```bsl
ОС = Новый Массив();
ОС.Добавить("ubuntu");
ОС.Добавить("windows");
Задача.Параллельность.ДобавитьРядМатрицы("OS", ОС);
```

### ДобавитьРяд(Ряд)

Ряд из соответствия — комбинации всех переменных ряда **перемножаются** (декартово произведение):

```bsl
Ряд = Новый Соответствие();
Ряд.Вставить("OS", ОС);
Ряд.Вставить("VERSION", Версии);
Задача.Параллельность.ДобавитьРяд(Ряд);
```

## Валидация

Число и матрица взаимоисключающие — одновременное задание роняет генерацию.

## Вывод

```yaml
# Число
parallel: 5

# Независимые ряды
parallel:
  matrix:
    - OS: [ubuntu, windows]
    - VERSION: ["17", "19"]

# Декартово произведение
parallel:
  matrix:
    - OS: [ubuntu, windows]
      VERSION: ["17", "19"]
```

Копии получают `CI_NODE_INDEX` и `CI_NODE_TOTAL`.
