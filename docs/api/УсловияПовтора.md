# УсловияПовтора

Модуль-константа условий повтора для `retry.when`. Полный набор допустимых значений GitLab (22 условия).

## Основные

| Метод | Значение |
|-------|----------|
| `Всегда()` | always |
| `СбойСкрипта()` | script_failure |
| `СбойРаннера()` | runner_system_failure |
| `СбойАПИ()` | api_failure |
| `НеизвестныйСбой()` | unknown_failure |

## Прочие

Остальные 17 условий (полный набор из 22): `ЗависаниеИлиТаймаут()`, `ОжиданиеРаннеров()`, `НетПодходящихРаннеров()`, `НетОбновленийПриЗапуске()`, `НетОбновленийПриОтмене()`, `ОшибкаКонфигурацииРаннера()`, `СбойВнешнейЗависимостиРаннера()`, `РаннерПрерван()`, `РаннерНеПоддерживается()`, `ПросроченнаяЗадача()`, `ПревышеноВремяВыполнения()`, `ТаймаутСервераПриЗапуске()`, `ТаймаутСервераПриОтмене()`, `ЗадачаВАрхиве()`, `НеВыполненыПредпосылки()`, `СбойПланировщика()`, `НарушениеЦелостностиДанных()`.

## Допустимые()

Возвращает массив всех допустимых значений — используется для валидации `ОписаниеПовтора.ДобавитьУсловие()`.

## Пример

```bsl
Задача.Повтор.ДобавитьУсловие(УсловияПовтора.СбойСкрипта());
```

Недопустимое условие — исключение с перечнем допустимых.
