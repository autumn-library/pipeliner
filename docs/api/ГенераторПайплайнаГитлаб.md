# ГенераторПайплайнаГитлаб

Собирает YAML пайплайна из накопленных задач и записывает в файл.

Получение:

```bsl
Генератор = Поделка.НайтиЖелудь("ГенераторПайплайнаГитлаб");
```

## СформироватьПайплайн(ПутьКФайлу)

Валидирует задачи и пишет YAML пайплайна.

```bsl
Генератор.СформироватьПайплайн(".gitlab-ci.yml");
```

**Параметры:**
- `ПутьКФайлу` - Строка - путь к файлу результата

**Валидации, выполняемые при генерации:**

| Проверка | Исключение |
|----------|-----------|
| `needs` ссылается на несуществующую джобу | С перечнем доступных джоб |
| `СтартоватьСразу` + непустой `Нуждается` | Взаимоисключающие настройки |
| `Окружение` заполнено без `Имя` | Нельзя построить валидный environment |
| `Окружение.Действие` не из набора | С перечнем допустимых |
| `Окружение.ПриОстановке` на несуществующую джобу | По образцу needs |
| `Релиз` заполнен без `Тег`/`Описание` | С именем задачи |
| Джоба `pages` без артефактов/публикации | Не опубликует ничего |
| Джоба `pages` не в стадии deploy | Требование GitLab |
| Параллельность: заданы и число, и матрица | Взаимоисключающие |

**Порядок топ-левел секций:** `default` → `stages` → `variables` → `coverage` → джобы.

Пустые значения не выводятся в YAML.
