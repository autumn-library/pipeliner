# Гитлаб

Модуль-помощник для работы с окружением GitLab и зарезервированными сущностями.

## ПолучитьПеременнуюСредыГитлаб(Переменная)

Возвращает значение переменной среды GitLab. При локальном запуске (вне CI), если переменная не задана, возвращает её имя с префиксом `$` — генерация пайплайна работает без окружения GitLab.

```bsl
Версия = Гитлаб.ПолучитьПеременнуюСредыГитлаб("CI_COMMIT_TAG");
// В CI: реальное значение
// Локально: "$CI_COMMIT_TAG"
```

## ИсточникСобытияПайплайна()

Значение `CI_PIPELINE_SOURCE`.

## ЭтоМержРеквест()

Истина, если пайплайн запущен событием мерж-реквеста.

## ЗарезервированныеСтадии()

Реестр зарезервированных стадий GitLab — единственное место их перечисления в библиотеке.

**Возвращаемое значение:** Соответствие, ключ → значение:

| Ключ | Значение |
|------|----------|
| `ДоВсех` | `.pre` |
| `ПослеВсех` | `.post` |

Генератор фильтрует эти стадии из `stages` по реестру; сахар `Задача.ДоВсех()`/`ПослеВсех()` берёт имена из него же. Новая зарезервированная стадия добавляется одной строкой в реестр.
