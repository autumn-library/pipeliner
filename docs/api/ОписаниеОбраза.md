# ОписаниеОбраза

Образ контейнера джобы (`image`).

Доступ: `Задача.Образ`

## Поля

| Поле | Тип | Описание |
|------|-----|----------|
| `Имя` | Строка | Имя образа, например `alpine:3.19` |
| `ПолитикаОбраза` | Строка | `pull_policy` (заполняется через методы ниже) |

## Методы

### ДобавитьКомандуЭнтрипоинт(Команда)

Добавляет команду в `entrypoint`.

### Энтрипоинт()

Возвращает массив команд `entrypoint`.

### УказатьПолитику(Политика)

Устанавливает `pull_policy` с валидацией. Допустимые значения:

- `always` — всегда скачивать
- `never` — никогда не скачивать
- `if-not-present` — скачать, если отсутствует локально
- `pull` — принудительно выкачивать (GitLab/раннер >= 15.1)

Недопустимое значение — исключение с перечнем допустимых.

### Сахар-методы (через УказатьПолитику)

| Метод | Политика |
|-------|----------|
| `Всегда()` | always |
| `Никогда()` | never |
| `ЕслиОтсутствует()` | if-not-present |
| `Принудительно()` | pull |

### ДопустимыеПолитики()

Возвращает массив допустимых политик.

## Пример

```bsl
Задача.Образ.Имя = "docker:latest";
Задача.Образ.Всегда();
```
