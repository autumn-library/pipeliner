# Скрипты

Модуль-фабрика команд для инструментов 1С-разработки на базе
[vanessa-runner 3.0](https://autumn-library.github.io/vanessa-runner/). Каждая функция
возвращает готовую строку команды для `Скрипты.Добавить()`.

Обязательные параметры — в начале, необязательные — со значением по умолчанию.
У команд, которые умеют работать через `ibcmd`, параметр `ИспользоватьИбкмд` по
умолчанию `Истина`; у команд запуска 1С — `ИспользоватьАвтономныйСервер` (`--ibsrv`).

| `ОбновитьКонфигурациюНаПоддержке(СтрокаПодключения, ФайлОбновления, ФайлНастроекОбъединения = Неопределено, Принудительно = Ложь, ОбновитьКонфигурациюБД = Истина)` | `cf vendor-update` |

## Прочее

- `ГенерацияОСкриптЛинукс(Скрипт, ИмяФайла)` — генерация выполняемого файла скрипта.
- `ВыполнитьОСкрипт(ИмяФайла, Параметры = Неопределено)` — запуск скрипта через `oscript`.
- `ЛогЭхоЛинукс(ТекстСообщения = "")` — `echo` с таймстампом.

## Пример

```bsl
Задача.Скрипты.Добавить(Скрипты.СозданиеБазы("/Fbuild/ib"));
Задача.Скрипты.Добавить(Скрипты.ЗагрузитьКонфигурациюИзФайлов("/Fbuild/ib", "build/src"));
Задача.Скрипты.Добавить(Скрипты.ОбновитьКонфигурациюБД("/Fbuild/ib"));
Задача.Скрипты.Добавить(Скрипты.ЗапускТестовЯксЮнит("/Fbuild/ib", "yaxunit.json"));
```
