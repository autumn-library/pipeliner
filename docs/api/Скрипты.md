# Скрипты

Модуль-фабрика команд для инструментов 1С-разработки. Каждая функция возвращает готовую строку команды для `Скрипты.Добавить()`.

## ЕДТ (1C:EDT CLI)

| Функция | Назначение |
|---------|-----------|
| `КонвертацияЕДТВКонфигуратор(КаталогВоркспейса, КаталогЕДТ, КаталогКонфигуратор, ПамятьВГБ = 8)` | Экспорт конфигурации из ЕДТ в формат конфигуратора |
| `ИмпортПроектаЕДТ(КаталогВоркспейса, КаталогЕДТ, ПамятьВГБ = 8)` | Импорт проекта в workspace |
| `ВалидацияЕДТПоСпискуПроектов(КаталогВоркспейса, СписокПроектов, ФайлРезультата, ПамятьВГБ = 8, ТаймаутВСек = 3600)` | Валидация по списку проектов |
| `ВалидацияЕДТПоСпискуКаталоговПроектов(...)` | Валидация с импортом по каталогам |

## vanessa-runner / vrunner

| Функция | vrunner-команда |
|---------|-----------------|
| `СозданиеБазы(СтрокаПодключения)` | `init-dev` |
| `ЗагрузитьКонфигурациюИзФайлов(СтрокаПодключения, КаталогИсходников)` | `compile -c` |
| `ЗагрузитьРасширениеИзФайлов(СтрокаПодключения, КаталогИсходников, ИмяРасширения)` | `compileext` |
| `ОбновитьКонфигурациюБД(СтрокаПодключения)` | `updatedb` |
| `СобратьКонфигурациюИзФайлов(КаталогИсходников, ПутьКФайлу)` | `compile` |
| `ОбновитьБазуВРежимеПредприятия(СтрокаПодключения, ПутьДоОбработки)` | `run` + обновление ИБ |
| `ЗапускТестовЯксЮнит(СтрокаПодключения, ФайлНастроек)` | YAXUnit |
| `ЗапускТестовВА(СтрокаПодключения, ФайлПараметровВА, ПутьОбработкиВА, КореньПроекта)` | Vanessa Automation |

## Прочее

- `НастройкаФлаговРасширения(ПолныйПутьКБазе, ИмяРасширения)` — ibcmd extension update
- `ЛогЭхоЛинукс(Текст)` — echo с таймстампом

## Пример

```bsl
Задача.Скрипты.Добавить(Скрипты.СозданиеБазы("/Fbuild/ib"));
Задача.Скрипты.Добавить(Скрипты.ЗагрузитьКонфигурациюИзФайлов("/Fbuild/ib", "build/src"));
Задача.Скрипты.Добавить(Скрипты.ОбновитьКонфигурациюБД("/Fbuild/ib"));
```
