# Скрипты

Модуль-фабрика команд для инструментов 1С-разработки на базе
[vanessa-runner 3.0](https://autumn-library.github.io/vanessa-runner/). Каждая функция
возвращает готовую строку команды для `Скрипты.Добавить()`.

Все функции возвращают `Строка`. Обязательные параметры — в начале, необязательные —
со значением по умолчанию. Необязательный параметр со значением `Неопределено` не
попадает в команду.

## Общие параметры

Эти параметры встречаются у большинства функций и описаны один раз здесь.

### СтрокаПодключения

Строка подключения к информационной базе в формате 1С:

- `/F<путь>` — файловая база, например `/Fbuild/ib`;
- `/S<сервер>\<база>` — серверная база, например `/Sserver\base`.

### ИспользоватьИбкмд

`Булево`, по умолчанию `Истина`. Добавляет флаг `--ibcmd`: операция выполняется
утилитой `ibcmd` вместо полного запуска платформы (быстрее, не требует запуска 1С).
У команд запуска 1С (`run`, `test`) этого параметра нет — там используется
`ИспользоватьАвтономныйСервер`.

### ИспользоватьАвтономныйСервер

`Булево`, по умолчанию `Истина`. Добавляет флаг `--ibsrv`: для команд `run`/`test`
vrunner поднимает автономный сервер и выполняет операцию в нём.

### Опции EDT (`--edt-*`)

Набор опций для команд, работающих с исходниками 1С:EDT. Передаются параметрами:

- `КаталогВоркспейсаЕДТ` — каталог рабочей области EDT (`--edt-workspace`); по
  умолчанию vrunner использует временный каталог, передавать не обязательно.
- `ФорматИсходников` — `auto` (по умолчанию), `edt` или `xml` (`--src-format`).
- `ПутьКЕДТ` — путь к `1cedtcli` (`--edt-path`), если утилита не в `PATH`.
- `ВерсияЕДТ` — версия EDT (`--edt-version`).
- `ТаймаутЕДТВСек` — таймаут операций `1cedtcli` в секундах (`--edt-timeout`).
- `ПамятьВГБ` — память для JVM (`--edt-vmargs=-Xmx<ПамятьВГБ>g`).

## Прочее (не vrunner)

### ГенерацияОСкриптЛинукс(Скрипт, ИмяФайла)

Генерирует shell-команду (`cat << 'EOF'`), которая записывает содержимое `Скрипт`
в файл `ИмяФайла`. Обычно используется, чтобы на лету создать oscript-скрипт в
пайплайне и затем запустить его через `ВыполнитьОСкрипт`.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `Скрипт` | Строка | Содержимое скрипта — oscript-код (многострочный текст) |
| `ИмяФайла` | Строка | Имя создаваемого файла, например `run.os` |

Пример:

```bsl
ТекстСкрипта = "Сообщить(""Сборка конфигурации началась"");";
Задача.Скрипты.Добавить(Скрипты.ГенерацияОСкриптЛинукс(ТекстСкрипта, "run.os"));
Задача.Скрипты.Добавить(Скрипты.ВыполнитьОСкрипт("run.os"));
```

Сгенерирует команду:

```sh
cat << 'EOF' > run.os
Сообщить("Сборка конфигурации началась");
EOF
```

### ВыполнитьОСкрипт(ИмяФайла, Параметры = Неопределено)

Запуск скрипта через `oscript`.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `ИмяФайла` | Строка | — | Путь к `.os`-файлу |
| `Параметры` | Массив из Строка | `Неопределено` | Аргументы командной строки, соединяются пробелом |

Пример:

```bsl
Параметры = Новый Массив();
Параметры.Добавить("--mode");
Параметры.Добавить("build");
Задача.Скрипты.Добавить(Скрипты.ВыполнитьОСкрипт("build/build.os", Параметры));
```

### ЛогЭхоЛинукс(ТекстСообщения = "")

Строка `echo` с таймстампом — для пометки этапов в логе пайплайна.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `ТекстСообщения` | Строка | `""` | Сообщение, например `"Сборка конфигурации"` |

Пример:

```bsl
Задача.Скрипты.Добавить(Скрипты.ЛогЭхоЛинукс("Сборка конфигурации"));
```

## cf — конфигурация

### СобратьКонфигурациюИзФайлов(КаталогИсходников, ПутьКФайлу, ИспользоватьИбкмд = Истина)

Сборка файла `.cf` из каталога исходников.

`vrunner cf compile [--ibcmd] -s <КаталогИсходников> <ПутьКФайлу>`

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `КаталогИсходников` | Строка | — | Каталог исходников (XML-выгрузка или EDT-проект), например `build/cf` |
| `ПутьКФайлу` | Строка | — | Путь к собираемому файлу, например `build/conf.cf` |
| `ИспользоватьИбкмд` | Булево | `Истина` | Флаг `--ibcmd` |

Пример:

```bsl
Задача.Скрипты.Добавить(Скрипты.СобратьКонфигурациюИзФайлов("build/cf", "build/conf.cf"));
```

### РазобратьКонфигурациюВИсходники(КаталогИсходников, ПутьКФайлу = Неопределено, СтрокаПодключения = Неопределено, ИспользоватьИбкмд = Истина)

Выгрузка конфигурации в исходники: из файла `.cf` либо из базы.

`vrunner cf decompile [--ibcmd] [--cf-file <ПутьКФайлу>] [--ibconnection <СтрокаПодключения>] <КаталогИсходников>`

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `КаталогИсходников` | Строка | — | Каталог для выгрузки исходников |
| `ПутьКФайлу` | Строка | `Неопределено` | Файл `.cf`; если не задан — выгрузка из базы |
| `СтрокаПодключения` | Строка | `Неопределено` | База, из которой выгружать (нужна, если не задан `ПутьКФайлу`) |
| `ИспользоватьИбкмд` | Булево | `Истина` | Флаг `--ibcmd` |

Пример:

```bsl
// из файла
Задача.Скрипты.Добавить(Скрипты.РазобратьКонфигурациюВИсходники("build/src", "build/conf.cf"));

// из базы
Задача.Скрипты.Добавить(Скрипты.РазобратьКонфигурациюВИсходники("build/src", , "/Fbuild/ib"));
```

|----------|-----|--------------|----------|
| `СтрокаПодключения` | Строка | — | База, например `/Fbuild/ib` |
| `КаталогИсходников` | Строка | — | Каталог исходников, например `build/src` |
| `ИспользоватьИбкмд` | Булево | `Истина` | Флаг `--ibcmd` |

Пример:

```bsl
Задача.Скрипты.Добавить(Скрипты.ЗагрузитьКонфигурациюИзФайлов("/Fbuild/ib", "build/src"));
```

### СоздатьФайлПоставки(СтрокаПодключения, ПутьКФайлу)

Создание файла поставки (`.cf` с полной поставкой) из базы.

`vrunner cf make-dist --ibconnection <СтрокаПодключения> <ПутьКФайлу>`

| Параметр | Тип | Описание |
|----------|-----|----------|
| `СтрокаПодключения` | Строка | База, например `/Fbuild/ib` |
| `ПутьКФайлу` | Строка | Файл результата, например `build/1Cv8-dist.cf` |

Пример:

```bsl
Задача.Скрипты.Добавить(Скрипты.СоздатьФайлПоставки("/Fbuild/ib", "build/1Cv8-dist.cf"));
```

### ОбъединитьКонфигурацию(СтрокаПодключения, ФайлКонфигурации, ФайлНастроекОбъединения, ПоставитьНаПоддержку = Ложь, СнятьСПоддержки = Ложь, Принудительно = Ложь)

Объединение конфигурации базы с файлом по настройкам объединения.

`vrunner cf merge -s <ФайлКонфигурации> --merge-settings <ФайлНастроекОбъединения> [--enable-support] [--disable-support] [--force] --ibconnection <СтрокаПодключения>`

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `СтрокаПодключения` | Строка | — | База, например `/Fbuild/ib` |
| `ФайлКонфигурации` | Строка | — | Файл `.cf` для объединения |
| `ФайлНастроекОбъединения` | Строка | — | Файл настроек объединения |
| `ПоставитьНаПоддержку` | Булево | `Ложь` | Флаг `--enable-support` |
| `СнятьСПоддержки` | Булево | `Ложь` | Флаг `--disable-support` |
| `Принудительно` | Булево | `Ложь` | Флаг `--force` |

Пример:

```bsl
Задача.Скрипты.Добавить(Скрипты.ОбъединитьКонфигурацию(
	"/Fbuild/ib", "build/vendor.cf", "build/merge.xml", Истина, Ложь, Ложь));
```

### ОбновитьКонфигурациюНаПоддержке(СтрокаПодключения, ФайлОбновления, ФайлНастроекОбъединения = Неопределено, Принудительно = Ложь, ОбновитьКонфигурациюБД = Истина)

Обновление конфигурации, стоящей на поддержке, из файла поставщика (`.cfu` или `.cf`).

`vrunner cf vendor-update -s <ФайлОбновления> [--update-settings <ФайлНастроекОбъединения>] [--force] [--no-update-db] --ibconnection <СтрокаПодключения>`

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `СтрокаПодключения` | Строка | — | База, например `/Fbuild/ib` |
| `ФайлОбновления` | Строка | — | Файл `.cfu` или `.cf` поставщика |
| `ФайлНастроекОбъединения` | Строка | `Неопределено` | Файл настроек объединения |
| `Принудительно` | Булево | `Ложь` | Флаг `--force` |
| `ОбновитьКонфигурациюБД` | Булево | `Истина` | Если `Ложь` — флаг `--no-update-db` |

Пример:

```bsl
Задача.Скрипты.Добавить(Скрипты.ОбновитьКонфигурациюНаПоддержке(
	"/Fbuild/ib", "build/vendor.cfu", "build/update.xml"));
```

### СравнитьКонфигурацию(ВторойФайл, ПервыйФайл = Неопределено, СтрокаПодключения = Неопределено, КаталогОтчета = Неопределено, ТипОтчета = Неопределено, ФорматОтчета = Неопределено)

Сравнение конфигураций: файл с файлом либо файл с базой.

`vrunner cf compare --second-cf <ВторойФайл> [--first-cf <ПервыйФайл>] [--ibconnection <СтрокаПодключения>] [--report-dir <КаталогОтчета>] [--report-type <ТипОтчета>] [--report-format <ФорматОтчета>]`

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `ВторойФайл` | Строка | — | Файл `.cf`, с которым сравниваем |
| `ПервыйФайл` | Строка | `Неопределено` | Первый файл `.cf`; если не задан — конфигурация из базы |
| `СтрокаПодключения` | Строка | `Неопределено` | База (нужна, если `ПервыйФайл` не задан) |
| `КаталогОтчета` | Строка | `Неопределено` | Каталог отчёта (по умолчанию текущий) |
| `ТипОтчета` | Строка | `Неопределено` | `Full` или `Brief` |
| `ФорматОтчета` | Строка | `Неопределено` | `txt` или `mxl` |

Пример:

```bsl
Задача.Скрипты.Добавить(Скрипты.СравнитьКонфигурацию(
	"build/new.cf", "build/old.cf", , "build/report", "Brief", "txt"));
```

### КонвертацияЕДТВКонфигуратор(КаталогЕДТ, КаталогКонфигуратор, ПамятьВГБ = 8)

Конвертация исходников между форматами: проект 1С:EDT ↔ XML-дамп Конфигуратора.

`vrunner cf convert -s <КаталогЕДТ> [--edt-vmargs=-Xmx<ПамятьВГБ>g] <КаталогКонфигуратор>`

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `КаталогЕДТ` | Строка | — | Проект 1С:EDT, например `build/edt` |
| `КаталогКонфигуратор` | Строка | — | Каталог XML-дампа Конфигуратора, например `build/cf` |
| `ПамятьВГБ` | Число | `8` | Память для JVM `1cedtcli` (флаг `--edt-vmargs=-Xmx<ПамятьВГБ>g`) |

Пример:

```bsl
Задача.Скрипты.Добавить(Скрипты.КонвертацияЕДТВКонфигуратор("build/edt", "build/cf", 16));
```

## infobase — информационная база

### СозданиеБазы(СтрокаПодключения, ИсточникКонфигурации = Неопределено, Расширения = Неопределено, Рекурсивно = Ложь, ИспользоватьИбкмд = Истина, КаталогВоркспейсаЕДТ = Неопределено, ФорматИсходников = Неопределено, ПутьКЕДТ = Неопределено, ВерсияЕДТ = Неопределено, ТаймаутЕДТВСек = Неопределено, ПамятьВГБ = Неопределено)

Создание информационной базы. Без `ИсточникКонфигурации` создаётся пустая файловая
база; при заданных `--src`/`--ext` за один вызов создаётся база, загружается
конфигурация и расширения, обновляется БД.

`vrunner infobase init [--ibcmd] --ibconnection <СтрокаПодключения> [--src <ИсточникКонфигурации>] [--ext <Расширение> ...] [--recursive] [--edt-*]`

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `СтрокаПодключения` | Строка | — | База, например `/Fbuild/ib` |
| `ИсточникКонфигурации` | Строка | `Неопределено` | Каталог исходников, файл `.cf` (с обновлением БД) или `.dt` (восстановление целиком) — `--src` |
| `Расширения` | Массив из Строка | `Неопределено` | Файлы `.cfe` или каталоги исходников расширений; имя расширения берётся из имени файла/каталога — повторяемая `--ext` |
| `Рекурсивно` | Булево | `Ложь` | Рекурсивный поиск источников — `--recursive` |
| `ИспользоватьИбкмд` | Булево | `Истина` | Флаг `--ibcmd` |
| `КаталогВоркспейсаЕДТ` | Строка | `Неопределено` | Каталог рабочей области EDT — `--edt-workspace` |
| `ФорматИсходников` | Строка | `Неопределено` | `auto`, `edt` или `xml` — `--src-format` |
| `ПутьКЕДТ` | Строка | `Неопределено` | Путь к `1cedtcli` — `--edt-path` |
| `ВерсияЕДТ` | Строка | `Неопределено` | Версия EDT — `--edt-version` |
| `ТаймаутЕДТВСек` | Число | `Неопределено` | Таймаут `1cedtcli` — `--edt-timeout` |
| `ПамятьВГБ` | Число | `Неопределено` | Память для JVM — `--edt-vmargs=-Xmx<ПамятьВГБ>g` |

Примеры:

```bsl
// Пустая файловая база
Задача.Скрипты.Добавить(Скрипты.СозданиеБазы("/Fbuild/ib"));

// База + конфигурация + два расширения, всё из исходников, рекурсивно
Расширения = Новый Массив();
Расширения.Добавить("build/ext/МоёРасширение.cfe");
Расширения.Добавить("src-ext/Интеграция");
Задача.Скрипты.Добавить(Скрипты.СозданиеБазы(
	"/Fbuild/ib", "build/src", Расширения, Истина));

// Исходники в EDT с явным воркспейсом
Задача.Скрипты.Добавить(Скрипты.СозданиеБазы(
	"/Fbuild/ib", "build/edt-project", , , Истина,
	"/tmp/edt-workspace", "edt"));
```
