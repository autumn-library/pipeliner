# ОписаниеСтраниц

Публикация GitLab Pages (`pages:publish`). Доступ: `Задача.Страницы`

Работает для джобы с именем **pages** — особого имени в GitLab.

## Поля

| Поле | Тип | YAML-ключ |
|------|-----|-----------|
| `ПутьЭкспорта` | Строка | `pages.publish` |

## Методы

### Публиковать(Путь)

Задаёт каталог публикации. Путь автоматически добавляется в `artifacts:paths` (GitLab 17.10+).

### ПутьПубликации()

Возвращает заданный путь.

## Валидации при генерации

- Джоба `pages` без публикации и без артефактов → исключение (публикации не будет)
- Джоба `pages` не в стадии `deploy` → исключение

## Пример

```bsl
Страницы = Фабрика.Новая();
Страницы.Наименование = "pages";
Страницы.Стадия = "deploy";
Страницы.Страницы.Публиковать("dist");
Страницы.Скрипты.Добавить("npx @11ty/eleventy --output=dist");
```

YAML:

```yaml
pages:
  stage: deploy
  script:
    - npx @11ty/eleventy --output=dist
  pages:
    publish: dist
  artifacts:
    paths:
      - dist
```
