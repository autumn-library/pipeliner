# ВидыОтчетов

Модуль-константа видов отчётов для `artifacts:reports`. Источник правды — именованные методы, набор `Допустимые()` наполняется из них.

## Методы-виды

| Метод | Значение |
|-------|----------|
| `Юнит()` | junit |
| `САСТ()` | sast |
| `ДАСТ()` | dast |
| `Дотенв()` | dotenv |
| `СканированиеЗависимостей()` | dependency_scanning |
| `ПоискСекретов()` | secret_detection |
| `КачествоКода()` | codequality |
| `СканированиеКонтейнеров()` | container_scanning |
| `САРИФ()` | sarif |
| `ЦиклонДХ()` | cyclonedx |
| `Терраформ()` | terraform |
| `ФаззингАПИ()` | api_fuzzing |
| `ФаззингПокрытия()` | coverage_fuzzing |
| `ПроизводительностьБраузера()` | browser_performance |
| `НагрузочныеТесты()` | load_performance |
| `Доступность()` | accessibility |
| `Аннотации()` | annotations |
| `Метрики()` | metrics |
| `Требования()` | requirements |

## Форматы покрытия

Для `ДобавитьОтчетПокрытия()`: `Кобертура()` (cobertura), `Джакоко()` (jacoco), `ЛКов()` (lcov), `СимплКов()` (simplecov).

## Справочные методы

- `Допустимые()` — массив всех допустимых видов
- `ФорматыПокрытия()` — массив допустимых форматов покрытия

## Пример

```bsl
Задача.Артефакты.ДобавитьОтчет(ВидыОтчетов.Юнит(), "junit.xml");
Задача.Артефакты.ДобавитьОтчетПокрытия(ВидыОтчетов.Кобертура(), "coverage.xml");
```
