# ЛокаторСтадийПайплайна

Загружает стадии пайплайна из `.os`-файлов каталога.

При инициализации поделки сканирует каталог (по умолчанию `./pipeline`) и подключает каждый `*.os`-файл как сценарий. Имя файла становится именем сценария.

## Настройка каталога

Каталог настраивается через `&Деталька` при создании (значение по умолчанию `./pipeline`).
