# ОписаниеСервиса

Сервис-контейнер джобы (`services`). Создание через фабрику задачи:

```bsl
Сервис = Задача.НовыйСервис();
```

## Поля

| Поле | Тип | YAML-ключ |
|------|-----|-----------|
| `Имя` | Строка | `name` |
| `Алиас` | Строка | `alias` |
| `Энтрипоинт` | Массив из Строка | `entrypoint` |
| `Команда` | Массив из Строка | `command` |
| `Переменные` | Соответствие | `variables` |

## Методы

### ДобавитьПеременную(Имя, Значение)

Переменная окружения сервиса.

## Пример

```bsl
База = Задача.НовыйСервис();
База.Имя = "postgres:14";
База.Алиас = "db";
База.ДобавитьПеременную("POSTGRES_PASSWORD", "secret");
```

YAML:

```yaml
services:
  - name: postgres:14
    alias: db
    variables:
      POSTGRES_PASSWORD: secret
```
