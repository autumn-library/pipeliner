# ОписаниеПайплайна

Топ-левел настройки пайплайна. Получение:

```bsl
ОписаниеПайплайна = Поделка.НайтиЖелудь("ОписаниеПайплайна");
```

## Поля

| Поле | Тип | YAML-ключ |
|------|-----|-----------|
| `ПередСкрипты` | Массив из Строка | `default.before_script` |
| `ПослеСкрипты` | Массив из Строка | `default.after_script` |
| `Переменные` | Соответствие | `variables` |
| `ШаблонПокрытия` | Строка | `coverage` |
| `Правила` | Массив | зарезервировано для `workflow` |

## Методы

### ДобавитьПередСкрипт(Команда)

Команда глобального `before_script`.

### ДобавитьПослеСкрипт(Команда)

Команда глобального `after_script`.

### ДобавитьПеременную(Имя, Значение)

Глобальная переменная пайплайна (выводится в корень `variables`).

## Пример

```bsl
ОписаниеПайплайна.ДобавитьПеременную("REGISTRY", "registry.example.com");
ОписаниеПайплайна.ШаблонПокрытия = "/^Total.*?(\d+\s*)$/";
ОписаниеПайплайна.ДобавитьПередСкрипт("opm install -l");
```
