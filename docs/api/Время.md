# Время

Модуль форматирования длительности для ключей вида `timeout`, `start_in`, `auto_stop_in`.

| Функция | Пример результата |
|---------|-------------------|
| `ВСекунды(2)` | `2 seconds` |
| `ВМинуты(30)` | `30 minutes` |
| `ВЧасы(2)` | `2 hours` |
| `ВДни(3)` | `3 days` |
| `ВНедели(1)` | `1 week` |
| `ВМесяцы(6)` | `6 months` |
| `ВГоды(2)` | `2 years` |

## Пример

```bsl
Задача.Таймаут = Время.ВЧасы(2);
Деплой.Окружение.АвтоОстановка = Время.ВНедели(1);
```
