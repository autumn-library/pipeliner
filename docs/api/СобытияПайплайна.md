# СобытияПайплайна

Модуль-константа условий запуска джобы (`when`). Сахар: функции возвращают строковые значения, IDE показывает варианты при наборе.

| Метод | Значение | Смысл |
|-------|----------|-------|
| `ПриУспехе()` | `on_success` | При успехе предыдущих (дефолт) |
| `ПриНеудаче()` | `on_failure` | Только при падении |
| `Всегда()` | `always` | Всегда, независимо от результата |
| `РучнойЗапуск()` | `manual` | По кнопке |
| `Отложенный()` | `delayed` | С задержкой `start_in` |

## Пример

```bsl
Задача.Когда = СобытияПайплайна.РучнойЗапуск();
```

Модуль содержит только when-константы. Константы стадий — на `ОписаниеЗадачи` (см. `ДоВсех()`/`ПослеВсех()`), условия повтора — в модуле `УсловияПовтора`.
