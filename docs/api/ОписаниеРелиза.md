# ОписаниеРелиза

Создание релиза из джобы (`release`). Доступ: `Задача.Релиз`

## Поля

| Поле | Тип | YAML-ключ | Обязательное |
|------|-----|-----------|--------------|
| `Тег` | Строка | `tag_name` | да |
| `Описание` | Строка | `description` | да |
| `СообщениеТега` | Строка | `tag_message` | нет |
| `Имя` | Строка | `name` | нет |
| `Реф` | Строка | `ref` | нет |
| `ДатаВыхода` | Строка | `released_at` | нет |
| `Вехи` | Массив из Строка | `milestones` | нет |
| `Ссылки` | Массив из Структура | `assets.links` | нет |

## Методы

### ДобавитьВеху(Веха)

### ДобавитьСсылку(Имя, УРЛ)

Ссылка на ассет релиза.

## Валидация

Заполнено что-то, но пустые `Тег` или `Описание` → исключение с именем задачи. Полностью пустой релиз → ключ не выводится.

## Пример

```bsl
Релиз.Релиз.Тег = "$CI_COMMIT_TAG";
Релиз.Релиз.Описание = "Что нового в $CI_COMMIT_TAG";
Релиз.Релиз.Имя = "Версия $CI_COMMIT_TAG";
Релиз.Релиз.ДобавитьСсылку("Дистрибутив", "https://example.com/distr.cf");
```
